# GL_TREND_V1 当前逻辑（完整）

这份文档描述线上**实际执行**的逻辑，参数取自代码常量与部署配置。
配置里为 `NULL` 的项一律使用下表默认值。

---

## 一、入场（`evaluate_open`）

**两套信号**，每次请求都算：

| 系统 | 判据 |
|---|---|
| **区间突破** | 收盘价高于前 `entry_period`（默认 20）根 K 线的最高点 → 做多；低于最低点 → 做空 |
| **回调结构** | 确认的波段高低点（左右各 2 根）同时抬高/降低 → 回调 ≥ `0.5 ATR` → 收盘突破前一个波段极值 → **且**满足确认（见下）|

**确认信号**（三选一即可）：EMA5 上穿/下穿 EMA10、吞没形态、Pin Bar —— 搜索范围 `5` 根 K 线。

**冲突处理**：两套方向不一致 → **本根放弃**（`趋势信号冲突`）。

**AI 风险闸门**：AI 说"不开" → 放弃；AI 说"开" → 放行；AI 没给可识别判定 → 重试一次，仍不行 → 放弃。

**入场时机保护**（三条，都会把市价单改成挂单）：

| 条件 | 动作 |
|---|---|
| **尖峰K线**：上一根已收盘 K 线振幅 > `2.0 × ATR` | 改挂单，挂在**该 K 线中点** |
| **美盘数据/开盘窗口**：**美东 08:30–10:30**（夏令时自动）| 改挂单，挂在**被突破的通道位** |
| 挂单价必须落在**市价后方** | 否则保持市价 |

## 二、手数（`_unit_lot`）

- `position_size_mode = fixed` → 用 `fixed_volume`（或 `lot`，默认 0.01）
- `position_size_mode = risk` → `手数 = 风险金额 ÷ 每手风险`；
  - `risk_base_mode = fixed_loss` → 用 `risk_amount`
  - `risk_base_mode = balance_percent` → 用余额 × `risk_percent%`
- **每手风险**只从 symbol_info 取（`tick_size/tick_value`、`value_per_price`、`point/value_per_point`、`contract_size`），
  并且**取其中一个"合理"的分支**（每手风险必须 ≥ 价格波动 ✓）
- **最小止损距离**：`point × stops_level`（EA 上报）→ 否则配置 `min_stop_distance_points` / `min_stop_distance_price`
  → 否则 **0.25 × ATR** 兜底（不会改变现有止损 ✓）

## 三、初始止损

```
止损 = 入场 ∓ 2.0 × ATR          （STOP_ATR = 2.0）
```

并经过：最小距离夹紧 → 方向可用性校验（不可用则本根不入场）。

---

## 四、加仓（`_maybe_add`）

**触发条件**（全部满足）：

1. `allow_add = true`
2. 只有单一方向
3. 持仓笔数 < `min(max_positions, 4)`
4. **价格比"最远入场"再延伸 ≥ `1.0 × ATR`**（`add_step_atr`，今天从 0.5 改为 1.0）

**加仓时同时**：

```
统一止损 = 最远入场 − 2×ATR
        ↓ 但不低于【首单入场】（basket_stop_floor = first_entry）
全部持仓的止损都移到这个位置（只紧不松）
```

且 AI 允许加仓（`allow_add` 由风控的 AI 判定）。

## 五、持仓保护（`evaluate_position`，每次请求按顺序）

| 顺序 | 规则 | 触发条件 | 动作 |
|---|---|---|---|
| 1 | **反向通道** | 价格跌破/突破前 `exit_period`（默认 10）根区间 | **整篮平仓** |
| 2 | **篮子止损** | 价格触及 `最远入场 − 2×ATR` | **整篮平仓** |
| 3 | **浮盈回吐保护**（新）| 峰值浮盈 ≥ `1.5 ATR` **且** 当前浮盈 < 峰值 × `50%` | **整篮平仓** |
| 4 | **加仓** | 见上 | 加一笔 + 统一止损 |
| 5 | **保本** | 该笔浮盈 ≥ `1.0 ATR` | 止损移到 `入场 + 点差缓冲` |
| 6 | **跟踪** | 该笔浮盈 ≥ `1.5 ATR` | 止损移到 **`现价 − 1.0 ATR`**（只紧不松）|
| 7 | **AI 主动止盈** | AI 返回 `close_now = true` | **整篮平仓** |

## 七、容易误解的三点

1. **跟踪没有"步长"** ✓ —— 门槛是 `现价 − 成本 ≥ 1.5 ATR`，一旦成立就**永久成立**
   （价格跌破这条线才暂停）；此后**每次请求**都重算 `现价 − 1.0 ATR`，
   **只要优于现有止损就移** ✓（涨 0.1 也移 ✓，不是每 0.5 ATR 移一次 ✗）。
2. **是"按笔"算的** ✓ —— 每一笔用自己的成本价判断 1.5 ATR 门槛；新加的那笔要**自己**
   赚到 1.5 ATR 才进入跟踪档，期间它挂在篮子止损上。
3. **只朝有利方向移** ✓ —— 新目标必须优于现有止损，否则不动（止损**永不放松** ✓）。
4. **加仓那一根会"抢"掉同一次的保本/跟踪** —— 加仓优先，保护动作在**下一次请求**生效。

## 八、与 PA_AGENT_V1 的区别（最容易混淆的地方）

| | **GL_TREND_V1** | **PA_AGENT_V1** |
|---|---|---|
| 保本触发 | 该笔浮盈 ≥ **1.0 ATR** | 该笔浮盈 ≥ **0.5 ATR** |
| 跟踪门槛 | 该笔浮盈 ≥ **1.5 ATR**（**从成本算**）| 现价距**止损** ≥ **1.0 ATR**（**从止损算**）|
| 跟踪距离 | 现价 − **1.0 ATR** | 现价 − **0.5 ATR** |
| 之后的移动 | **每次请求**只要有优于现有止损的新目标就移 | **距止损再次 ≥1.0 ATR** 才移 |
| **净步长** | **不固定**（有新高就移）| **固定 0.5 ATR** |
| 可配置 | ✅ `break_even_atr` / `trailing_start_atr` / `trailing_distance_atr` | ❌ 写死在代码里 |
